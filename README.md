# С днём рождения! 💗

Простой романтический сайт на русском языке. Только один файл `index.html` — без установки библиотек.

## Как изменить имена

Откройте `index.html` в текстовом редакторе и найдите внизу блок `const CONFIG`.
Измените `girlfriendName` и `yourName`. При желании можно также поменять текст поздравления прямо в HTML.

## Как проверить

Дважды щёлкните файл `index.html`, чтобы открыть сайт в браузере.

## Как опубликовать на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub, например `birthday-surprise`.
2. Загрузите `index.html` в корень репозитория через **Add file → Upload files**, затем нажмите **Commit changes**.
3. Перейдите в **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Ссылка появится в настройках Pages. Обычно адрес: `https://USERNAME.github.io/birthday-surprise/`.

Примечание: опубликованный сайт будет общедоступным для любого человека со ссылкой (и потенциально других посетителей). Не добавляйте приватную информацию, которую не хотите раскрывать.
